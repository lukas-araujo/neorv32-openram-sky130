# NEORV32 + SRAM OpenRAM em SkyWater 130nm

Material do curso: geração de SRAM com OpenRAM, integração como
periférico de um RISC-V NEORV32, síntese no Cadence e layout no
LibreLane.

## Conteúdo

- `aulas/` — roteiros das aulas
- `DIARIO.md` — diário de bordo do projeto
- `rtl/` — Verilog e VHDL
- `openram/` — configurações do compilador de memória
- `synth/` — scripts de síntese e verificação (Genus, Conformal)
- `librelane/` — fluxo aberto até GDSII
